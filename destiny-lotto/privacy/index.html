이 방침은 현재 앱의 데이터 처리 방식을 설명합니다.

1. 처리 목적

사주의 수는 사용자가 입력한 정보를 사주·운세·오늘의 숫자·숫자 흐름 및 조합 풀이를 기기에서 제공하는 데 사용합니다. 사용자가 선택적으로 동의하면 Firebase Analytics로 기능 이용 현황을 분석하여 서비스를 개선합니다. 계정 생성이나 로그인 기능은 없습니다.

2. 기기에 저장하는 정보

생년월일, 양력·음력 및 윤달 여부, 출생시간 또는 모름 여부, 성별과 사주 계산에 필요한 설정값은 기기의 앱 전용 SharedPreferences에 저장됩니다. 사용 통계 동의 상태도 analytics_consent_v1에 저장됩니다. 기존 버전에서 생성된 추천 기록과 관련 로컬 데이터가 남아 있을 수 있으나 현재 앱은 복권·QR 기능을 제공하지 않습니다.

3. 기기 내 계산

사주 원국, 오행·용신·희신, 오늘·주간·월간 운세, Daily Number, 입력 숫자의 흐름과 조합 풀이는 기기에서 계산합니다. 사주 프로필 원문이나 사용자가 입력한 숫자 원문을 놀소록이 운영하는 별도 서버로 전송하는 앱 코드는 없습니다.

4. Firebase Analytics 사용

Firebase Analytics는 Google이 제공하는 분석 서비스입니다. 앱은 수집을 기본 OFF로 설정하며, 사용자가 동의한 경우에만 활성화합니다. 동의한 경우 앱 인스턴스 식별자, 기기·OS 및 앱 정보, 세션·앱 실행 정보, IP 주소에서 유추한 대략적 지역 등 Firebase의 기본 분석 정보가 처리될 수 있습니다. SDK가 자동 기록하는 앱 수명주기·화면 관련 이벤트도 포함될 수 있습니다.

5. 앱이 보내는 사용 이벤트

앱은 동의한 경우에만 다음 기능 사용 이벤트 7종을 전송합니다: home_view, daily_number_detail_open, number_flow_submit, number_flow_result_view, my_saju_view, weekly_fortune_view, monthly_fortune_view. 이 커스텀 이벤트에는 별도 parameter를 넣지 않습니다. 앱 개발자는 Analytics에 User-ID나 User Property를 설정하지 않습니다. 광고 ID 수집은 앱 설정에서 비활성화하고 Android 광고 ID 권한도 제거하도록 구성합니다.

6. Analytics로 보내지 않는 정보

앱 코드는 생년월일, 출생시간, 성별, 양력·음력·윤달 여부, 사주 원국·오행·용신·희신, 운세 점수, 오늘의 숫자 실제 값, 사용자가 입력한 숫자와 조합 결과, 해석 문구, roleName/actionTags, 프로필 식별정보를 커스텀 Analytics 이벤트에 담지 않습니다. 이는 Firebase가 동의 후 처리할 수 있는 기본 분석 정보가 없다는 뜻은 아닙니다.

7. 동의 방식과 선택권

동의 여부를 선택하지 않은 상태와 거절한 상태에서는 Analytics 수집이 OFF입니다. 사용자는 최초 안내에서 선택하거나 내 정보 → 앱 정보 및 안내 → 사용 통계 수집에서 언제든 ON/OFF를 변경할 수 있습니다. 동의하지 않아도 앱의 모든 기능을 사용할 수 있습니다. OFF로 변경하면 이후 Analytics 수집이 중단됩니다.

8. Google 및 다른 처리 주체

동의 후의 Analytics 정보는 Google의 Firebase 서비스를 통해 처리됩니다. 놀소록은 사주 원문이나 입력 숫자 내용을 Google Analytics에 직접 전달하지 않으며, 별도 놀소록 서버에도 저장하지 않습니다. Google이 서비스 제공 과정에서 처리하는 정보와 Play Data Safety의 수집·공유 구분은 Google의 현재 계약·프로젝트 설정과 Play Console 기준을 게시 전 확인합니다. 앱은 현재 광고 SDK나 광고 요청 기능을 포함하지 않습니다.

9. 보관 및 삭제

사주 프로필과 기존 앱 기록은 앱의 내 데이터 삭제 기능으로 제거할 수 있습니다. 이 기능은 Analytics 동의 상태나 이미 Google에 전송된 분석 정보를 삭제하지 않습니다. 동의 상태는 앱 정보에서 변경할 수 있고, 앱 데이터 삭제 또는 앱 삭제 시 기기의 앱 전용 저장 정보와 함께 제거됩니다. 동의를 철회해도 이전에 전송된 집계·분석 정보가 즉시 소급 삭제되는 것은 아닙니다. Firebase 측 보관 기간과 삭제 절차는 운영 설정을 별도로 확인합니다.

10. Android 백업

앱은 android:allowBackup=false로 설정되어 있으며, 백업·데이터 추출 규칙에서 SharedPreferences를 포함한 앱 저장 영역을 클라우드 백업과 기기 간 전송 대상에서 제외하도록 구성합니다. 운영체제와 제조사별 실제 동작에는 차이가 있을 수 있습니다.

11. 아동 관련 안내

현재 앱은 계정 또는 연령 확인 기능을 제공하지 않습니다. 사주 계산용 생년월일 입력을 이용 연령 확인으로 사용하지 않습니다. 배포 대상 연령과 아동 관련 Google Play 설정은 출시 전 별도로 결정합니다.

12. 보안 조치

입력 정보는 앱 전용 로컬 저장 영역에 보관하고 Android 백업·기기 전송에서 제외하도록 설정합니다. Google은 Firebase Analytics 데이터가 전송 중 TLS로 보호된다고 안내합니다. 앱 이용자는 기기 잠금과 운영체제 업데이트를 유지할 수 있습니다.

13. 방침 변경

앱 기능, 외부 서비스, 수집 항목 또는 처리 방식이 달라지면 이 방침과 Google Play Data Safety 안내를 함께 갱신합니다.
